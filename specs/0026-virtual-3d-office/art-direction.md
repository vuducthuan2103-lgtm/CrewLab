# Virtual Office — Art Direction and Asset Brief

## Palette and material language

| Material | Direction |
| --- | --- |
| Primary architecture | warm limestone / ivory microcement, pale oak, satin off-white |
| Metal | brushed champagne or quiet aluminum; no chrome sci-fi edges |
| Greenery | deep-to-soft natural greens, uneven but curated foliage |
| Glass | low-reflection architectural glazing, soft sky reflections |
| Accent | CrewLab electric lime only for selected / real action moments |
| Warnings | semantic product colour + shape/icon/motion; never lime |

## Light and atmosphere

Daylight enters through skylight and glazing. Shadows are soft and consistently directed. Evening retains the same layout and identity with warm practical lights and moderate display luminance. Do not use rain, fog, purple/blue wash, floor grids, giant holograms, particles, or alarm lighting.

## Six character briefs

| Agent | Character read | Workstation signature |
| --- | --- | --- |
| A01 | grounded coordinator, calm senior presence | central planning desk and abstract workflow material |
| B02 | considered researcher | curated research shelf and source-card structure |
| B03 | organized planner | tactile planning surface and calendar blocks |
| D01 | expressive writer | copy desk, notebooks, text-column abstractions |
| D02 | visual maker | image pin-up / thumbnail review surface, stylus or material samples |
| E01 | focused reviewer | comparison table and quality-check surface |

Characters are authored, fixed versions. Use a shared humanoid rig convention and role-specific state clips. At overview distance, blink, gaze and posture are enough; no lip-sync.

## World-screen rule

World screens may show abstract, semantic blocks, thumbnails, compare surfaces and charts. They must not reproduce Portal UI, show paragraphs, or carry text a user needs to read.

## Asset delivery requirements

- Runtime: optimized GLB/glTF first; compressed texture pipeline when assets exist.
- One character identity sheet per agent: front/3/4 silhouette, wardrobe/material notes, workstation prop list and state poses.
- Each third-party source must record licence, source URL, allowed use, modification status and attribution requirement before inclusion.
- Test all final visual assets for mobile memory budget and reduced-quality tier.
